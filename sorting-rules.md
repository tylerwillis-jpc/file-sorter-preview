# Sorting rules

Plain-English rules for where files go. Edit this file to change them: no code changes needed.
Claude receives this rulebook with every suggestion request and names the rule it followed.
Everyone sorting should follow these too, so decisions stay consistent.

## Folder names

- **Construction & Development** is the construction folder. "PM Construction" (from the old S drive) means the same thing.
- Only the approved top-level folders can be chosen. Subfolders are not sorted yet.

## Rules

- Warranties → **Bldg Information & Measurements**
- Invoices and pay applications → **Accounting**
- Certificates of insurance (COIs) → **Insurance**
- Title policies, title reports and preliminary title → **Title**
- Phase I / Phase II environmental reports → **Environmental**
- Leases, amendments and LOIs for a lease → **Leasing & Marketing** (signed tenant files → **Tenants**)
- Building permits, plan check comments and permit fees → **Permits_License Agreements**
- As-built drawings and floor plans of the finished building → **Bldg Information & Measurements**
- Contractor change orders, submittals and RFIs → **Construction & Development**
- Loan documents and lender correspondence → **Financing**
- Photos with no clear topic → **Graphics & Images**
